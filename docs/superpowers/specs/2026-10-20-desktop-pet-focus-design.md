# 桌面陪伴宠物「小番茄」设计稿

日期：2026-10-20  
状态：已确认，核心版本已实现  
目标平台：Windows 10/11

## 1. 产品定位

「小番茄」是一款常驻 Windows 桌面的可爱陪伴宠物软件。它帮助用户工作一会儿、按时起身活动、记住重要时间、管理 Todo，并用轻量而温柔的方式提醒用户有新的微信通知。

它不是一个强打断的效率工具，而是一个有状态、有称呼、有小动作的桌面伙伴。所有提醒都应优先使用动画和小字气泡，只有用户明确设置为重要时才使用声音或持续提示。

宠物默认昵称为“小番茄”，用户可以在软件中修改昵称、颜色和性别。它保持圆润的暖橙色身体、嫩叶小芽、奶油色腹部和发光的小钟；小钟既表达番茄钟，也可作为通知指示灯。角色概念稿已经验证了三个核心状态：专注工作、起身伸展、收到新消息。

## 2. 第一版范围

### 包含

- 透明、无边框、可拖动、可置顶的桌面宠物浮窗
- 软件名固定为“小番茄”，宠物昵称默认为“小番茄”，可自定义
- 宠物性别、主色和辅助色设置
- 常驻托盘图标和右键菜单
- 番茄钟：工作时段、短休息、长休息和循环
- 工作一段时间后的起身活动提醒
- 准点提醒：一次性、每天、工作日、自定义星期重复
- 称呼设置：固定称呼、自定义称呼和预览
- Todo 清单：直接记录任何事情，可选目标日期/时间、倒数、完成、稍后处理和临近截止时提高提醒频率
- Todo 支持公历/农历、倒数本/清单、置顶和重复规则
- 节日、生日、纪念日、房贷等都作为普通 Todo 记录，不设置特殊业务类型
- 暖心 tips 和生活小常识的本地内容库
- Windows 系统通知中的微信新消息轻提示
- 勿扰时段、声音/动画开关、透明度和桌面位置设置
- 开机启动、暂停提醒、退出应用
- 有统一视觉设计的设置页和桌面控制面板

### 暂不包含

- 读取微信聊天记录或直接登录微信
- 云端账号、跨设备同步或社交功能
- 复杂的宠物养成、道具商城或付费系统
- 第一版实时 3D 骨骼渲染
- 自动替用户发送微信消息

## 3. 核心用户体验

### 3.1 桌面浮窗

默认显示在屏幕右下角，大小约为 280–360 px 的可调浮窗。窗口背景必须真正透明：桌面只看到角色、气泡和必要的小控件，不出现白色或矩形底板。窗口透明、无边框、始终置顶但不抢焦点；拖动角色本体可以移动位置，右键打开托盘式菜单，双击打开设置。

浮窗中只显示角色、当前状态和必要的小字，不持续显示复杂的计时数字。用户把鼠标移到角色上时，角色会看向鼠标或做一个轻微回应；长时间没有交互时进入低频待机动画。

### 3.2 番茄钟与起身提醒

用户可以选择预设模式（例如 25/5、50/10）或自定义工作/休息时长。工作结束时，小番茄先做动作，再显示一行短提示，例如“站起来走两步吧”。

起身提醒不会默认弹出系统级强提醒。用户可在设置中选择：仅动画、动画加声音、或必须点击确认。点击“稍后提醒”可以延后若干分钟，点击“开始休息”进入休息计时。

### 3.3 准点提醒

准点提醒与番茄钟分开管理。每条提醒包含时间、重复规则、文字、提醒强度和启用状态。提醒文案支持使用称呼变量，例如“{称呼}，该喝水啦”。

若设备从睡眠或应用暂停状态恢复，应用会检查错过的提醒：普通提醒不追溯弹出，重要提醒只提示一次并标记为错过，避免恢复后连续打扰。

### 3.4 节日与日期

第一版支持中国常见传统节日和可更新的法定节假日数据，但这些数据只作为日期选择和可选提醒来源，不创建“生日”“房贷”等特殊对象。用户最终保存的仍是一条普通 Todo，例如“妈妈生日”“每月交房贷”“提交材料”。法定节假日不写死在业务代码中，而是作为可替换的数据文件，避免年份变化导致错误。

### 3.5 称呼与人格

设置页提供“我希望你怎么称呼我”和宠物昵称编辑、预览。默认宠物昵称为“小番茄”，默认不使用任何真实姓名；用户主动填写后，小番茄才在文案中使用。宠物性别支持“不设定、男、女”三档，主要影响语气和自称，不改变功能。提醒模板尽量自然短小，不重复称呼，不在每条通知都强行插入称呼。

### 3.6 微信通知

应用只尝试读取 Windows 系统通知中的微信通知，不访问微信数据库、聊天窗口或账号登录态。默认只保留“发件人”这一层信息，并在内存中完成解析；不保存消息正文、通知原文或历史记录。

当通知格式可可靠解析时显示类似“阿宁找你啦”；无法确定发件人时显示通用提示“微信有新消息”。用户可以关闭微信通知、设置仅在工作时接收、或使用勿扰时段。首次启用时必须明确展示权限说明和关闭入口。

Windows 不同版本、微信版本和安装方式可能造成通知读取能力不同。应用需要展示“已连接 / 等待授权 / 当前不可用”状态，不以绕过系统权限的方式补偿。

### 3.7 Todo 清单与倒数日

Todo 是一个本地“事情清单”，不按业务类型拆分。每条记录包含：事情名称、可选备注、可选目标日期/时间、公历/农历、倒数本/清单、置顶、重复规则、完成状态、提醒策略和创建时间。用户可以在设置中心或桌面控制面板新增、完成、编辑、延后、置顶和归档 Todo。没有目标日期的 Todo 就是普通待办，不显示倒数，也不会因为临近日期增加提醒频率。

参考图中的交互在软件中保持同样的结构：顶部填写“事件名称”；有需要时开启“目标日”，选择公历或农历；可选择倒数本/清单；可以置顶；最后选择不重复、每天、每周、每月或每年等重复规则。房贷、生日、纪念日和工作事项只是一条条不同标题的 Todo，不需要用户先选择类型。

Todo 支持自定义分组。默认提供“未分组”，用户可以创建、改名、排序、归档和删除分组；删除分组只会把其中的 Todo 移到“未分组”，不会删除 Todo。每条 Todo 有一个星标开关，星标 Todo 会进入“重要”智能视图；星标只表达重要性，不自动改变提醒频率。

主界面提供三个不需要用户维护的智能视图：“我的一天”（今天到期或今天安排的 Todo）、“重要”（星标 Todo）和“全部任务”。下面是用户自定义分组，每个分组显示未完成数量。Todo 可以在分组之间移动，列表中的星标可以直接点击切换。

随机提醒只发生在用户允许的工作时段，并遵守勿扰设置。默认“标准”策略为：没有截止时间的 Todo 每天最多提醒一次；距离截止日超过 7 天时每天最多一次；3–7 天时每天最多两次；1–2 天时约每 3 小时一次；截止当天约每 90 分钟一次且每天最多五次；逾期后约每 60 分钟一次且每天最多五次。用户可以切换“轻柔/标准/积极”策略，也可以对单条 Todo 暂停提醒。

随机提醒不使用生硬的系统弹窗，而是由小番茄做一个注意动作并显示短气泡，例如“要不要顺手处理一下：提交报销”。用户可以点击“完成”“稍后”或“今天不再提醒”。有目标日期的 Todo 在桌面控制面板中显示“还剩 X 天”“今天到期”或“已过期”；重复 Todo 在完成后按下一次目标日期重新计算。

### 3.8 界面视觉设计

软件界面与宠物视觉保持同一套设计语言：暖象牙白背景、暖橙主色、奶油色卡片、鼠尾草绿辅助色、少量薰衣草紫用于消息状态。页面使用圆角卡片、柔和阴影、清晰的层级和较大的留白，避免工具软件的密集表格感。

设置中心采用左侧轻量导航和右侧卡片内容，分为“今天、专注、Todo、倒数本、外观、提醒与隐私”。Todo 主界面参考用户提供的布局：左侧是搜索、智能视图和自定义分组，右侧是当前分组的任务列表，任务行有完成圆圈、标题、星标和可选的日期/倒数信息。首页优先显示当前番茄钟、今日 Todo、最近倒数日和小番茄状态。桌面宠物点击后弹出小型控制面板；平时不常驻大面板，保持桌面干净。

颜色设置使用预设主题色并允许自定义主色；系统自动计算对比度，保证气泡和按钮可读。界面主题支持浅色、深色和跟随系统；深色主题借鉴参考图的侧栏/列表层级，但保留小番茄自己的暖橙和奶油色点缀。透明宠物窗口与设置中心的实体卡片形成对比，让“桌面陪伴”和“功能管理”边界清楚。

## 4. 视觉与动画设计

### 4.1 视觉语言

- 软糯的 3D 立体感，但第一版以轻量 2D/2.5D 资产实现
- 暖橙、奶油白、鼠尾草绿和少量薰衣草紫
- 圆润轮廓、大面积留白、低对比度阴影
- 不使用尖锐警告色，不让角色看起来像系统错误提示

### 4.2 动画状态

- `idle`：呼吸、眨眼、叶子轻晃
- `focus`：安静陪伴、偶尔看向小钟
- `stretch`：举手伸懒腰、星星闪一下
- `message`：转向消息气泡、轻轻点亮腹部小钟
- `celebrate`：完成休息或完成一组番茄钟后的短庆祝
- `sleep`：低频打瞌睡，避免高刷新率长期占用资源
- `attention`：用户主动点击或拖动时的短回应

动画由状态机统一驱动，计时器、定时提醒和通知接入只发送状态事件，不直接操作具体素材。这样后续替换为 Live2D 或更完整的骨骼动画时，不需要重写业务逻辑。

## 5. 技术方案

采用 **Tauri 2 + React + TypeScript + Vite**，以 Windows 原生桥接满足桌面能力：

- 前端负责设置页、状态展示、动画编排和本地文案
- Tauri 窗口负责透明、无边框、置顶、拖动、托盘和启动行为
- Rust/Windows bridge 负责需要系统权限的通知监听、系统时间和权限状态
- 本地配置使用 JSON 或 SQLite 轻量存储；第一版优先 JSON，数据量变大后再切换
- 动画素材使用版本化的 PNG/WebP 帧或可组合图层，不依赖网络

选择 Tauri 的原因是它更适合长时间常驻桌面，内存开销低；同时保留前端迭代可爱交互和动画的灵活性。与 Electron 相比，打包体积和常驻成本更可控；与纯 WinUI/WPF 相比，角色表现和设置界面更容易快速迭代。

## 6. 模块边界

### `PetWindow`

管理透明窗口、位置、置顶、拖动和鼠标交互。它不决定什么时候提醒，只负责显示当前状态和主题色。

### `PetStateMachine`

接受 `timer_started`、`break_due`、`reminder_due`、`wechat_notice` 等事件，输出唯一的当前角色状态和动画优先级。重要状态可以暂时覆盖待机状态，事件完成后回到原状态。

### `FocusTimer`

维护工作、短休息、长休息和暂停/恢复状态。纯逻辑模块，提供可测试的剩余时间和状态变化，不依赖界面。

### `ReminderScheduler`

管理准点提醒、重复规则、勿扰时段和错过提醒策略。与番茄钟分离，避免一类提醒改动影响另一类。

### `TodoStore` / `TodoReminderPolicy`

保存 Todo、自定义分组、完成/延后状态、星标和单条提醒设置；根据截止时间、当前时间、工作时段和提醒策略计算下一次随机提醒，不直接操作 UI。删除分组时执行“移到未分组”的迁移，不删除 Todo。

### `TodoDateService`

负责 Todo 的公历/农历日期转换、目标日期重复计算、倒数天数和“提前提醒”时间。它不识别生日、房贷等业务类型，只处理 Todo 的日期字段，并复用同一套本地日期持久化和勿扰规则。

### `CalendarService`

提供传统节日、法定节假日数据和用户日期。法定节假日数据可版本化替换，用户日期存储在本地。

### `NotificationBridge`

封装 Windows 通知监听权限、微信通知解析和能力状态。它只向上层输出最小字段：来源、发件人（可空）、时间和能力状态。

### `TipsLibrary`

提供本地暖心 tips 和常识，按工作状态、休息状态、节日和随机间隔筛选。第一版不联网，不把 tips 与私人数据绑定。

### `SettingsStore`

集中管理设置、迁移版本和默认值。所有模块通过明确的数据接口读取设置，避免组件直接修改文件。

## 7. 数据与隐私

本地保存：用户称呼、宠物昵称/颜色/性别、Todo、Todo 分组、星标、提醒配置、节日数据版本、界面主题、界面偏好和应用版本。  
仅内存：微信通知原文、消息正文、解析中的临时文本。  
不保存：聊天记录、微信账号信息、联系人列表、截图或通知历史。

用户可以在设置页看到通知权限状态，并一键关闭微信监听。应用不需要网络才能完成番茄钟、节日提醒和暖心 tips；网络不是第一版运行依赖。

## 8. 错误与降级

- 透明窗口不可用：退化为普通无边框窗口，并提示用户重新启动
- 无法置顶：保留浮窗位置，显示在托盘状态中
- 微信通知权限未授予：只关闭微信能力，不影响其他提醒
- 微信通知格式不认识：显示通用“有新消息”提示，不展示不确定的正文
- 节假日数据过期：保留传统节日和用户日期，提示更新数据
- 设备休眠后计时漂移：以系统时间重新计算剩余时间，不依赖前端 tick 次数
- 配置文件损坏：备份损坏文件，恢复默认配置，并提示用户
- Todo 目标日期无效：提示用户修正；目标日期早于创建时间时允许保存并标记为“已过期”，不自动删除
- 自定义颜色对比度不足：自动使用可读的文字颜色，并在设置页显示预览
- 自定义分组重名：提示用户修改名称，不自动覆盖已有分组
- 删除分组：二次确认后将 Todo 移到“未分组”，不删除 Todo

## 9. 验收标准

第一版完成的判断标准：

1. 应用可在 Windows 10/11 启动，名称显示为“小番茄”，显示可拖动且真正透明的小番茄浮窗。
2. 小番茄至少能完成待机、专注、伸展、消息和庆祝五种动画状态切换。
3. 番茄钟可以开始、暂停、恢复、跳过和完成一轮，并在工作结束时发出起身提醒。
4. 用户可以在设置页修改称呼、工作/休息时长、提醒时间、节日选项、声音和勿扰时段。
5. 准点提醒在正常运行和从睡眠恢复后都不会重复轰炸用户。
6. 微信通知能力有明确授权状态；成功时只展示发件人或通用提示，不保存正文。
7. 关闭微信监听后，应用不再读取或处理微信通知。
8. 常驻运行时动画低频、可暂停，不能持续占用明显的 CPU 资源。
9. 用户可以新增、完成、延后 Todo；截止日期临近时随机提醒频率按策略提升，完成或暂停后不再继续提醒。
10. 用户可以直接记录任意事情；目标日期可选，支持公历/农历、倒数本、置顶和重复；生日、纪念日、房贷不需要特殊类型。
11. 用户可以创建、改名、排序和删除自定义分组；删除分组不会删除其中的 Todo。
12. Todo 可以加星，并出现在“重要”智能视图；“我的一天”和“全部任务”可以正确筛选和计数。
13. 用户可以修改宠物昵称、颜色、性别；界面支持浅色、深色或跟随系统，并具有统一的卡片式视觉设计。
14. 关键逻辑有自动化测试，关键桌面行为有人工验收清单。

## 10. 实施顺序

1. 建立 Tauri 项目骨架、设置数据模型和窗口/托盘壳子，产品名固定为“小番茄”。
2. 完成小番茄浮窗、状态机、透明背景和第一批轻量动画。
3. 完成番茄钟、起身提醒和准点提醒。
4. 完成 Todo、截止时间、随机提醒频率、完成/延后、星标和自定义分组。
5. 完成设置中心视觉系统、宠物昵称/颜色/性别、称呼和勿扰。
6. 接入 Todo 的公历/农历、倒数本、置顶、重复和倒数日计算；节日数据只作为日期选择/可选提醒来源。
7. 接入 Windows 通知权限与微信通知桥接，完成隐私提示和降级状态。
8. 做 Windows 打包、启动、睡眠恢复、多屏/DPI 和资源占用验证。
