# 小番茄多语言设计说明

## 目标

在设置中增加语言选项，使小番茄的主要界面、任务操作、设置项、宠物话语和 Tips 可以切换语言，并把语言选择持久化到本地设置。第一版支持简体中文、English、日本語、한국어、العربية。

## 范围

- 设置页增加“语言”选项，默认简体中文。
- 语言切换后立即刷新当前窗口和桌面宠物的文案，不需要重启。
- 翻译范围包括：窗口标题栏、侧栏导航、任务列表与编辑器、分组管理、设置页、番茄钟、提醒、空状态、错误提示、宠物互动话语和 Tips。
- 日期、星期、数字和相对日期使用当前语言的 `Intl` 格式化能力；农历仍沿用现有农历逻辑，只替换显示语言。
- 阿拉伯语启用 `dir="rtl"`，并对标题栏、侧栏、表单、任务行和弹窗做镜像布局；图标和倒计时数字保持可读方向。
- 未完成或缺失的翻译通过语言包回退到简体中文，不显示 key。

## 不在范围内

- 不改变 Todo、番茄钟、提醒、同步文件和宠物动画的业务逻辑。
- 不引入在线翻译、远程语言包或第三方账号同步。
- 不把用户输入的 Todo 标题、昵称、分组名自动翻译。

## 实现方案

### 语言模型

在 `AppSettings` 增加 `language: AppLanguage`，其中 `AppLanguage` 为 `zh-CN | en | ja | ko | ar`。旧设置通过 `normalizeSettings` 自动补上 `zh-CN`，保存时保留其他设置不变。

### 翻译层

新增无第三方依赖的 `src/i18n` 模块：

- `types.ts`：语言类型、方向类型、翻译 key 类型。
- `catalog.ts`：五种语言的静态语言包。
- `I18nProvider.tsx`：根据设置提供 `t(key, variables)`、当前 `locale` 和 `direction`。
- `formatters.ts`：日期、时间、数量和倒数显示的语言化格式化。

`App` 在最外层提供 i18n，上层设置变化后向 `SettingsWindow` 和宠物运行时发送新的语言与方向快照。现有组件逐步把硬编码用户可见文字替换为翻译 key；用户输入内容原样显示。

### Tips 与宠物话语

现有 Tips 和交互话语改为按语言分组的静态资源。随机选择仍使用现有频率和权重逻辑；如果某语言资源暂时不足，先从该语言资源选择，不足时回退中文，保证不会出现空白提示。

### RTL 规则

- 根窗口设置 `dir` 和 `data-language`。
- CSS 使用逻辑属性或 RTL 覆盖规则处理左右布局。
- 数字、时间、快捷键、代码路径和 Todo 标题保持 `dir="ltr"` 或 `unicode-bidi: plaintext`，避免倒序。
- SVG 图标不做镜像，方向性图标（返回、展开）按 RTL 需要单独处理。

## 验收标准

- 设置页可以选择五种语言，刷新或重启后选择仍保留。
- 切换语言后，侧栏、任务列表、设置、弹窗、宠物提醒和 Tips 不再混用中文固定文案。
- Arabic 模式下主要界面从右向左排列，倒计时和数字仍正常阅读。
- 缺失 key 有中文回退，并在开发测试中能报告缺失翻译 key。
- 旧版本设置数据可正常加载，未设置语言时默认中文。
- 不影响现有 Todo、番茄钟、桌面宠物、同步文件和窗口操作。

## 测试策略

- 设置存储测试：旧数据迁移、语言往返保存、非法语言回退中文。
- i18n 测试：五种语言 key 完整性、变量插值、缺失 key 回退、方向值。
- UI 测试：设置中的语言选择、切换后文案刷新、Arabic `dir="rtl"`。
- 运行现有全量 Vitest、TypeScript/Vite 构建和便携版启动检查。
