# 小番茄桌面宠物与 Todo 同步增量规格

日期：2026-10-20  
状态：已确认  
目标平台：Windows 10/11

## 目标

修复小番茄桌面宠物没有真正显示的问题，并把主窗口、透明宠物、系统托盘、应用图标和 Todo 同步文件串成一个可用的 Windows 桌面体验。

## 功能范围

### 透明宠物窗口

- 打包版点击主界面的宠物按钮后，必须显示真正的无边框透明 `pet` 窗口。
- 宠物窗口始终置顶、跳过任务栏、可拖动，不显示白色或矩形底板。
- Windows 透明窗口使用 `noRedirectionBitmap`，前端的 `html/body/#root` 也必须透明。
- 创建或显示失败时，打包版显示明确的错误提示；只有浏览器预览才可以显示内嵌预览弹窗。

### 主窗口和托盘

- 主窗口的关闭按钮不退出进程，只隐藏到系统托盘。
- 最小化和最大化按钮继续对应原生窗口操作。
- 系统托盘使用小番茄图标，右键菜单提供：打开小番茄、显示/隐藏桌面宠物、开机启动、退出软件。
- 托盘左键或双击可以重新打开主窗口。
- 开机启动使用当前用户的 Windows Run 注册表项；关闭开机启动时删除该项。

### Todo 同步文件

- 文件名默认为 `小番茄-Todo.csv`，CSV 使用 UTF-8 BOM，Excel 可以直接打开。
- 用户在设置中填写同步文件的完整路径并开启同步；推荐把文件放在 OneDrive、坚果云或其他同步文件夹中。
- 启动、主窗口重新获得焦点和用户点击“立即同步”时读取外部文件；Todo 或分组变更后自动写回。
- 每条 Todo 携带稳定 `id` 和 `updatedAtMs`；同步时按单条记录的较新更新时间合并，不以整表覆盖另一台电脑。
- CSV 同时保存 Todo 与自定义分组，保存标题、备注、目标日期/时间、公历/农历、分组、置顶、星标、重复、提醒、完成状态和更新时间。
- 没有同步路径、浏览器预览或文件读写失败时，主应用仍可正常使用本地 Todo，并展示简短状态。
- CSV 的缺失列按默认值补全；未知列忽略；非法行不应导致整个应用崩溃。

### 图标

- 更新 `icon.svg` 为圆角矩形底板内的立体小番茄宠物形象。
- 重新生成 ICO、PNG 和安装包资源，使桌面、任务栏、托盘和安装程序使用同一套图标。

## 非目标

- 不实现云账号、云端数据库或后台同步服务。
- 不直接读写微信聊天记录。
- 不把生日、纪念日、房贷拆成不同 Todo 类型。
- 不在本次增量中引入 Excel 专用格式；CSV 是唯一同步格式。

## 验收标准

1. 点击宠物按钮能在 Windows 打包版显示透明宠物，不再出现“打包后才会显示”的预览提示。
2. 点击主窗口右上角关闭后，窗口消失但托盘图标仍在；托盘右键可以打开、显示/隐藏宠物、切换开机启动和退出。
3. 重新安装后的桌面/任务栏图标是圆角矩形里的小番茄，而不是旧图标。
4. 开启 CSV 同步后，在另一台电脑选择同一个同步文件，启动或获得焦点时可以合并 Todo、分组和星标。
5. 自动化测试覆盖 CSV 转义/解析、同步合并、Todo 更新时间和窗口动作；`pnpm test`、TypeScript 检查、Tauri Windows 构建均通过。
