## 编辑与安全检查

- 五类有不同侧重：身体是基础照顾，心理是任务拆解与思绪整理，财务是记录与安排，心情是联结与兴趣，生活重置是环境和状态的切换。
- 只给低门槛动作，不写神奇效果、医学机制、诊断、服药或补剂剂量，不要求固定饮水量、步数、运动次数或洗澡频率。没有屏幕休息秒数和护眼疗效主张。
- 不含投资、资产配置、借贷产品、收益或回报承诺；不假设用户有可储蓄的结余，不鼓励压缩必要生活开支。
- 联系对象以舒适和信任为前提，允许联系朋友；没有要求用户维持不舒服的家庭关系或立刻得到回复。
- 不确定去留的物品先留存或待确认；重置不依赖消费，不鼓励强制丢弃、购买或完成整套家务。
- `body-3`、`body-5`、`body-13`、`body-14` 等姿势与休息场景，`mind-1`、`mind-6`、`mind-7`、`mind-9` 等启动与收尾场景，以及 `reset-1`–`reset-15`，属于原创生活组织建议；不把具体动作描述为临床结论。
- 用户气泡只有提示正文；来源、接口和工程说明保留在本文件，不混入提示文字。

## 接口与接入说明

保留 `getRandomTip(random?: () => number): string` 和 `getTips(): string[]` 的旧用法。`getTips()` 每次返回新数组；`TIP_CATEGORIES`、`TIP_LIBRARY` 及其中的记录在运行时冻结，导出类型为只读。

新增类型 `TipCategory`、`PracticalTip`、`TipSelectionOptions`、`ChooseTipOptions`，以及 `chooseTip(options?: ChooseTipOptions): PracticalTip`。记录包含 `id`、`category`、`text`，ID 前缀为 `body` / `mind` / `money` / `mood` / `reset`；保持现有分类内顺序，仅在该分类末尾追加，可保持已有 ID 不变。

```ts
const oldStyle: string = getRandomTip();
const deterministic: string = getRandomTip(() => 0.5);
const texts: string[] = getTips();

// 调用方保存自己实际显示过的正文，并在下一次选择时传入。
const nextText = getRandomTip(Math.random, { previousTip: lastDisplayedText });
const nextRecord = chooseTip({
  category: '生活重置',
  previousTip: lastDisplayedText,
  random: Math.random,
});
// 显示成功后，由调用方保存 nextText 或 nextRecord.text。
```

`getRandomTip` 的可选第二参数支持 `category` 和 `previousTip`（上一条的完整正文，不是 ID）。先按类别筛选，再排除上一条，随后只取一次随机值，不通过反复抽签重试，所以常量 RNG 也不会卡住。有多个候选时，均匀 RNG 对每条合格提示的选择机会相同。所有现有分类都具有多个候选；若将来某分类只剩一条，则优先保留类别并允许返回该条。

随机值小于 0 时取首个候选，大于等于 1 的有限值取末个候选；`NaN` 和正负无穷回退到首个候选。有效类别由 `TipCategory` 约束。历史由调用方持有，模块没有共享的上一条状态；不传历史的旧调用仍可能随机重复。本次不修改宠物运行时或设置窗口，调度方后续可直接使用上述第二参数避免连续重复。没有引入时段过滤或当前时间依赖。
